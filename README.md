# Trafotech Systems - Modern EHV Power & Substation Solutions

Flagship responsive web portal for **Trafotech Systems**, specialized in EPC & turnkey solutions for Extra High Voltage (EHV) substations and transmission lines up to 400 kV, transformer protection, live line maintenance, and smart grid automation.

## Features
- **Cinematic Experience:** Hardware-accelerated dynamic hero background video with topographic elevation contour styling.
- **KPI Metrics:** Responsive count-up counter animation for key achievements (400kV+, 14+ Clients, 50+ Years Experience, 100% Safety).
- **Interactive Directory:** 14 state utilities and multinational partner showcases (POWERGRID, MSETCL, MSPGCL, Adani, Tata Power, GE, ABB, Siemens, Toshiba, BHEL, etc.).
- **Completed Projects Gallery:** High-resolution field engineering project lightbox.
- **Instant WhatsApp Integration:** One-click tender quote requests and quotation form pre-typed WhatsApp message dispatcher to `+918855847066`.
- **Fully Responsive:** Pixel-perfect layout across mobile, tablet, and PC viewports.

## Deployment on Vercel
This project is configured for instant zero-configuration static deployment on Vercel:
1. Import repository into Vercel.
2. Framework Preset: **Other**.
3. Root Directory: `./` (or default).
4. Click **Deploy**.
